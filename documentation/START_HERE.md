# 🚀 START HERE - Quiz-Course Linking Feature

## ⚡ Quick Setup (30 Seconds)

### 1️⃣ Execute SQL (REQUIRED)

Open your terminal and run:

```bash
mysql -u your_username -p 3a8 < database.sql
```

Replace `your_username` with your MySQL username.

### 2️⃣ Run Your Application

Start your JavaFX application normally.

### 3️⃣ Test It!

1. **Main Menu** → Click "Manage Quizzes"
2. **Create a quiz** and select a course from the dropdown
3. **Main Menu** → Click "Browse Course Catalog"
4. **View course details** → See your quiz listed!

## 🐛 Troubleshooting

### "Cannot find course_quizzes table"
→ You forgot to execute the SQL! Run the command above.

### "Course dropdown is empty"
→ Create some courses first in Course Management.

### "No quizzes in Course Catalog"
→ Make sure you linked the quiz to a course in Quiz Management.
