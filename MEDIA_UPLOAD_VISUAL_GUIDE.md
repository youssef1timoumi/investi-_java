## 📁 File System Structure

```
Project Root
│
├── media/
│   └── courses/
│       ├── README.md                      ← Info about folder
│       ├── course_1709000000000.mp4      ← Uploaded video 1
│       ├── course_1709000001000.pdf      ← Uploaded PDF 1
│       ├── course_1709000002000.mp4      ← Uploaded video 2
│       └── course_1709000003000.avi      ← Uploaded video 3
│
├── src/
│   └── main/
│       ├── java/
│       │   └── edu/connections3a8/controllers/
│       │       ├── CourseController.java
│       │       │   └── handleBrowseFile()  ← Upload logic
│       │       │
│       │       └── CourseCatalogController.java
│       │           └── createMediaViewer() ← Display logic
│       │
│       └── resources/
│           └── CourseForm.fxml
│               └── Browse button           ← UI element
│
└── database (MySQL)
    └── course table
        └── content_url column
            ├── "media/courses/course_xxx.mp4"
            ├── "media/courses/course_xxx.pdf"
            └── "https://youtube.com/..."
```

## 🔄 Data Flow Diagram

```
┌─────────────┐
│   Admin     │
│  (Upload)   │
└──────┬──────┘
       │
       │ 1. Clicks Browse
       ↓
┌──────────────┐
│ FileChooser  │
└──────┬───────┘
       │
       │ 2. Selects file
       ↓
┌──────────────────┐
│ handleBrowseFile │
└──────┬───────────┘
       │
       │ 3. Copy file
       ↓
┌──────────────────┐
│ media/courses/   │
│ course_xxx.mp4   │
└──────┬───────────┘
       │
       │ 4. Store path
       ↓
┌──────────────────┐
│    Database      │
│  content_url     │
└──────┬───────────┘
       │
       │ 5. User views
       ↓
┌──────────────────┐
│ Course Catalog   │
└──────┬───────────┘
       │
       │ 6. Load media
       ↓
┌──────────────────┐
│ createMediaViewer│
└──────┬───────────┘
       │
       │ 7. Display
       ↓
┌──────────────────┐
│  Video Player    │
│  or PDF Button   │
└──────────────────┘
```

## 🎯 File Type Detection

```
File Extension          Content Type        Display Method
─────────────────────────────────────────────────────────
.mp4                →   video           →   MediaPlayer
.avi                →   video           →   MediaPlayer
.mkv                →   video           →   MediaPlayer
.mov                →   video           →   MediaPlayer
.wmv                →   video           →   MediaPlayer
.flv                →   video           →   MediaPlayer
.pdf                →   pdf             →   Open Button
http://...          →   url             →   Hyperlink
https://...         →   url             →   Hyperlink
```

## 📊 File Size Indicators

```
Small File (<10MB):     ⚡ Instant upload
Medium File (10-50MB):  ⏱️ Few seconds
Large File (50-200MB):  ⏳ 10-30 seconds
Huge File (>200MB):     ⏰ 30+ seconds
```
