INSTALLATION INSTRUCTIONS:

1. REQUIREMENTS:
   - Windows 10/11 (64-bit)
   - Java 17 or higher
   
2. CHECK IF YOU HAVE JAVA:
   - Open Command Prompt (cmd)
   - Type: java -version
   - If you see version 17 or higher, you're good!
   
3. IF YOU DON'T HAVE JAVA:
   - Download from: https://adoptium.net/
   - Install "Eclipse Temurin JDK 17"
   - Restart your computer
   
4. RUN THE APP:
   - Double-click INVESTI.exe
   - The app will start!
